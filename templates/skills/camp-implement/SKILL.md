# 定点实现辅助

先读目标及父目录 README 与实际调用方，仅修改已授权范围，保留无关变更。当前共用职责见 ../../basecamp/WORKFLOW.md。

1. 明确要改变的行为、写入位置、调用方及完成标准；按任务选择最小实现，不增设固定运行器或交付合同。
2. 实验候选只写对应实验目录并通过参数调用，不能自行覆盖共享基线。正式接入需主控和用户相应授权。
3. 验证有效引用、实际入口、编码和相关行为；只运行与修改直接相关的测试。不用本地通过冒充视觉识别提升。
4. 供应商调用遵守本任务指定模型与次数；框架验证调用0。凭据只引用外部入口，不输出具体内容。
5. 若是旧项目迁移，另遵守仓库 AGENTS 的源路径、源 SHA 与迁移决定记录要求；这仅适用于真实迁移，不扩展成日常岗位交接检查。

回报改动、验证、证据路径、局限和剩余问题。使用共用收发室，不自行创建对话或追加研究。
