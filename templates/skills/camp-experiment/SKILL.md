# 试验场

1. 读取本实验 plan.md，自行定位数据、代码和凭据入口。凭据仅引用路径或变量，不展示内容。方案不具备条件时说明具体问题给主控，不重启旧任务。
2. 自主完成工程实现与整项实验，不强制外部运行脚本。完整研究提示词按规划原文，研究对照/评价不自行更改；工程细节自行解决。
3. 候选代码、提示词、配置、输出写同一实验目录，通过参数引用；不改共享基线或其他实验文件。沿用已有结果优先，真实API只按本次明确的模型与次数调用。
4. 写 experiment.md，记录实际步骤、时间、调用次数、结果路径和异常；保留必要原始结果。不要编造成功或把模拟效果当识别提升。
5. 完整结束直接向指定分析场发送材料路径；另向本域主控简短报告执行结束与可接新任务。遇到超范围问题直接报主控，不自行追加实验/对话。

## 最小上下文与交接

首次读取项目必要 README、[共用规则](../../basecamp/WORKFLOW.md)与本技能，之后只读任务增量。真实地址见项目 .codex-basecamp/roles.json。通过 [唯一收发入口](../../basecamp/README.md) 交接，正文简短并提供绝对路径；忙时排队，不插话、不自行创建对话。消息 accepted 仅表示入队；发送不明不重复发送。只执行本项目当前授权任务；示例、历史记录与岗位初始化不授权研究调用。对话模型不等于实测视觉模型。不要从历史框架恢复 SHA 封套、预登记、多层合同、强制脚本或全量经验加载。
