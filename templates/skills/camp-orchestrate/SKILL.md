# 主控

与用户讨论研究目标、设计取舍或纠正理解时，按需读取[共同设计技能](../camp-discuss/SKILL.md)：主动调查、提出推荐、用具体情景检查理解，并将决定与理由写入本域已有讨论记录。普通状态查询、结果接收与明确执行不经过访谈；本域用户已授权事项不重复审批。各业务域 共用方法，各自保有研究安排权。

1. 将已授权问题说清：目标/已有证据/实验目录/配对规划和试验岗/指定分析岗/每模型调用次数/完成标准。只主控可创建对话和安排新实验。
2. 规划直接交配套试验场，试验场直接交指定分析场。收到执行结束即可考虑补位，无需等待分析。按共用规则优先初始与必要后续，空位再短补充；完整初始目标接收后截止补充。
3. 接收分析时看本次证据、局限、与已有结论的关系，记录接受/延期/后续决定。同系列稳定归属，两个域不混排材料与授权。
4. 只在问题需要时调查，不让送达核验成为每任务前置关卡；未知发送不盲重发。整理直属主控，删除移动先给精确范围和保留方案。
5. 提示词写作使用 camp-dispatch，模型设置见 references/model-policy.md；期望与实际验证分开记录。研究候选采用遵守用户决定，不因效果好自动改基线。

## 已授权的多批研究

用户安排多批连续研究时，使用本域一份夜间状态，由主控独占更新：当前批、初始/必要后续/补充任务、已接收分析、待派发项，以及已用/结果不明占用/已分配未用/未分配次数。回报到达先恢复增量状态。批次严格串行；本批初始和必要后续均已接收，停止执行中的补充并收尾已交分析的补充后，才能开始下一批。关闭本批和派下一批在同一次处理内完成，不等用户再说继续；部分派发逐项记录，发送不明不重发。批内补充默认零调用，额度只在本域授权总额内分配，不因空闲制造实验。收到响应后的解析问题优先离线修复。

无人值守兜底使用经过验证、附于本域主控的原生定时唤醒，正常回报仍是主要触发。只检查未回报、未处理结果和待接续批次，不打断工作、不重复派发，不另建常驻监控。无行动项安静结束。完成、取消或明确终止后停用；接口存在不等于已实测可靠。

## 最小上下文与交接

首次读取项目必要 README、[共用规则](../../basecamp/WORKFLOW.md)与本技能，之后只读任务增量。真实地址见项目 .codex-basecamp/roles.json。通过 [唯一收发入口](../../basecamp/README.md) 交接，正文简短并提供绝对路径；忙时排队，不插话、不自行创建对话。消息 accepted 仅表示入队；发送不明不重复发送。只执行本项目当前授权任务；示例、历史记录与岗位初始化不授权研究调用。对话模型不等于实测视觉模型。不要从历史框架恢复 SHA 封套、预登记、多层合同、强制脚本或全量经验加载。
