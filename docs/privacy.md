# 公开范围与隐私边界

公开包包含运行器、通用岗位技能、使用说明和模拟测试。发布时使用独立Git历史与通用维护者身份，不携带私人讨论、实际岗位地址、内部项目名称、源路径、源提交指纹或个人模型偏好。公开仓库的所有者账号、公开提交与发布文件本身可被任何人读取。

`provenance.json`仅记录本次公开文件的相对路径及SHA-256，不记录内部来源。它用于核对文件完整性，不是数字签名，也不包含它自身的哈希。修改发布文件时应同步更新清单。

展开后的`.codex-basecamp/`保存实际岗位地址、消息回执和本机配置，默认被Git忽略；`.env`与`config.local.json`也被忽略。认证由用户本机Codex管理，不随框架复制。

忽略规则不会清除已跟踪文件的历史，也不会自动处理业务代码、讨论或消息里的私人信息。使用本框架创建的项目是否公开，应由项目所有者单独决定；框架不会自动发布目标项目。
